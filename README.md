# Project Agent

**Project Agent** is a desktop application designed for AI interaction and automated task planning. It supports both **Google Gemini** and **OpenRouter**.

---

## Download

Download the latest Windows installer here:

👉 **[Download Project Agent v1.0.0 (Setup.exe)](https://github.com/kasiwat-p/project-agent/releases/latest)**

---

## Installation

1. Download `ProjectAgent_Setup_v1.0.exe` from the link above.
2. Double-click the file to run the setup installer.

> [!IMPORTANT]
> ** Security Note (Windows SmartScreen):**
> If Windows displays a *"Windows protected your PC"* warning, click **More info** -> then click **Run anyway** to proceed with the installation.

---

## Getting Started

1. Launch **Project Agent**.
2. Navigate to the **API Keys & Settings** menu on the left sidebar.
3. Select your preferred provider (**Google Gemini** or **OpenRouter**).
4. Paste your API Key, select a primary model, and click **Save Key**.
5. Select a **Workspace Folder** (the local folder where the AI is permitted to read and write project files).
